## ✨ Features

WinTuner is built from the ground up to safely optimize, debloat, and manage your Windows operating system without relying on dangerous, irreversible scripts.

- 🚀 **Startup Manager**: Safely audit and disable unnecessary startup applications that slow down your boot times.
- 🧹 **Disk Cleanup Engine**: Safe, evidence-based disk recovery that enforces preview-first transparency and never deletes personal files.
- 🛡️ **Privacy & Tracking**: Apply conservative, 100% reversible privacy rules to stop telemetry without breaking Windows Updates.
- 💻 **Windows Experience**: Revert to the classic context menu, disable annoying widgets, and strip away OS-level ads.
- ⚙️ **Services & Tasks**: Stop and disable heavy background telemetry services safely—protected system services are strictly locked to prevent OS corruption.
- 🌍 **Full Localization**: Native support for multiple languages including English, O'zbekcha, Français, Deutsch, and Русский.

## 📥 Installation (v1.0.0-demo)

Since this is a closed-source application, you can download the compiled executables directly from the **Releases** page.

1. Go to the [Releases](../../releases/latest) page on the right side of this repository.
2. Download `WinTuner-Setup-1.0.0.exe` for the automated installer.
3. **Double-click the installer**. 
   *(Note: WinTuner requires Administrator privileges to modify the Windows registry and manage services. You will be prompted by Windows UAC to grant permission).*
4. Enjoy a faster, cleaner Windows experience!

> *Portable versions (`WinTuner-Portable.zip`) are also available in the release assets if you prefer not to install the app.*
